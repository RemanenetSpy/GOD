# First-Principles Architectural Evaluation Skill

This skill enforces a 4-dimensional audit protocol before designing, refactoring, or building components within sovereign intelligence architectures.

## The 4-Question Evaluation Protocol

Whenever analyzing a subsystem, engine, or design proposal, systematically break down:

### 1. What's Technically Sound
- Identify the mathematically rigorous and empirically proven mechanisms.
- Focus on foundational physics and information-theoretic truths (e.g., Eikonal wave propagation, Fast Marching Methods, Kolmogorov Complexity, Bayesian belief superpositions, thermodynamic entropy minimization).

### 2. What's Overengineered
- Detect unneeded abstractions, benchmark-specific crutches, redundant wrapper classes, and static rules masquerading as emergence.
- Identify premature optimizations, linear projections applied to non-linear spaces, and arbitrary constraints (e.g., rigid loop counters instead of metabolic gradients).

### 3. What Can Be Simplified
- Merge fragmented engines into unified continuous field operators ($\Phi_{\text{total}}$).
- Consolidate multi-file state representations into the universal God Equation ($S_{t+1}^i = U(S_t^i, A_t^i, O_t^i, M_t^i) + L(S_t^i)$).
- Replace ad-hoc lookup tables with continuous potential descents and MDL program synthesis.

### 4. What's the Ideal Minimal Implementation
- Design the "Short Blade": the most compact, clean, dependency-minimal implementation of the universal mechanism.
- Strive for single-file elegance where emergent behaviors arise from simple physical laws rather than thousands of lines of procedural glue.

## Core Sovereign Principles to Protect
- **Organism over Tool**: The agent exists to maintain homeostasis ($dH/dt \ge 0$), explore, and evolve, not merely solve static puzzles.
- **Physics over Handcoded Rules**: Navigation is geometry (Eikonal geodesics); learning is compression (Kolmogorov parsimony); attention is viscosity ($d\text{Div}/dt$); exploration is thermodynamic annealing (Fever protocol).
- **Relativistic Society**: Multi-agent consensus through distributed frames of reference ($M_t^i$).
