**Theorem** (Solomonoff, 1964): The shortest program that fits the data is the most likely to generalize.

**Why This Matters**:
1. **Objective**: Program length is measurable (unlike "manifold structure")
2. **Universal**: Works for ANY data (not just grids)
3. **Sample-Efficient**: Occam's Razor prefers simple explanations
4. **Compositional**: Programs can call subroutines

**Evidence**: 
- GPT models work because they compress text
- JPEG works because it compresses images
- Evolution works because DNA compresses survival strategies

---

### The Three Equations (Revised)

**Equation 1: Σ (Filter Efficiency) = Compression Ratio**
```
Σ = Original_Entropy / Compressed_Entropy
  = |Input| / |Program|
```
- High Σ: Short program (good filter)
- Low Σ: Long program (poor filter)
- **Advantage**: Cannot collapse (program length is always positive)

**Equation 2: dH/dt (Metabolism) = Compression Profit**
```
dH/dt = Δ(Compression) per timestep
      = |Old_Program| - |New_Program|
```
- Positive: Agent found shorter explanation (gains energy)
- Negative: Agent's model became more complex (loses energy)
- **Advantage**: Intrinsic motivation (no external rewards needed)

**Equation 3: Λ (Friction) = Incompressibility**
```
Λ = Kolmogorov Complexity of residual error
  = |Shortest program for (Actual - Predicted)|
```
- Low Λ: Errors are compressible (systematic)
- High Λ: Errors are random (irreducible)
- **Advantage**: Distinguishes signal from noise
