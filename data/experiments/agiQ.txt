## Core Logic Questions

### 1. **Abstraction & Generalization**
- Can your AGI recognize the SAME pattern across different visual representations?
- Example: "Fill enclosed area" works on rectangles, circles, irregular shapes?
- Or does it only work on axis-aligned rectangles?

### 2. **Few-Shot Learning**
- How many training examples does it need to learn a new pattern?
- 1 example? 3 examples? 10?
- ARC is designed for few-shot (1-5 examples max)

### 3. **Compositionality**
- Can it handle MULTIPLE rules in one task?
- Example: "Fill rectangles with blue AND rotate 90 degrees"
- Or does it only handle single-rule tasks?

### 4. **Out-of-Distribution Handling**
- What happens when you give it a COMPLETELY novel pattern it's never seen?
- Does it fail gracefully? Make random guesses? Hallucinate?

### 5. **Uncertainty Quantification**
- When it's unsure, does it KNOW it's unsure?
- Your "belief uncertainty" maps - do they accurately reflect when the system doesn't understand the pattern?

## Specific ARC Challenges

### 6. **Symmetry Detection**
- Can it recognize and apply: reflection, rotation, translation symmetries?
- These are common in ARC but require abstract spatial reasoning

### 7. **Object Segmentation**
- Can it identify separate "objects" in a grid?
- Example: Multiple disconnected shapes that need individual processing

### 8. **Counting & Arithmetic**
- Can it count objects and use that count in transformations?
- Example: "Fill N cells where N = number of blue objects"

### 9. **Negative Space**
- Can it reason about EMPTY spaces as meaningful?
- Example: "The holes between objects matter"

### 10. **Temporal/Sequential Reasoning**
- If shown a sequence (A→B→C), can it predict D?
- Not just spatial, but temporal patterns
